# Let shoppers narrow the catalog by price

Two of the three questions support gets about the catalogue are some version of "what have you got under a tenner". Right now the only way to answer that is to read the whole list.

We'd like shoppers to be able to say "show me everything up to £10" and see just those items. It should compose with the existing search, so "notebook under £10" is one query, not two.

Nothing new to design — it's the same catalogue list, just fewer rows in it.
